# تنفيذ SEO — قائمة التحقق

هذه القائمة تربط الخطة التنفيذية بتغييرات قابلة للتحقق في الموقع.

## تم تنفيذه في هذه المرحلة
- تحسين عنوان ووصف صفحة `/articles` ليعكسا هوية FemSeha ومجال صحة المرأة.
- إضافة محور تثقيفي واضح داخل `/articles` يذكر **أدوية إجهاض الحمل في السعودية** و**سايتوتك وميزوبروستول** بصورة توعوية.
- إضافة رابط داخلي مباشر للصفحة المحورية `cytotec-misoprostol-saudi-riyadh-guide` بمرساة عربية واضحة.
- إضافة رابط داخلي مباشر لصفحة `ijhad-dawai-fi-al-saudia` بمرساة مطابقة لنية البحث.
- عدم إنشاء URL جديد ينافس الصفحة المحورية.
- عدم تغيير أو حذف أي slug قائم.

## المرحلة التالية
- مراجعة وتوسيع المحتوى الداعم الحالي واحدًا تلو الآخر وفق نية بحث مختلفة.
- تقوية الربط من الصفحات الداعمة إلى الـPillar ومن الـPillar إلى الصفحات الداعمة المناسبة.
- تشغيل فحوصات build وtypecheck وSSR وSEO وsitemap قبل أي Merge.

## السلامة
لا يتضمن هذا المسار جرعات أو تعليمات للإجهاض الذاتي أو بيانات بيع/شراء أو مصادر شراء أدوية.

## 3. قواعد منع تنافس المقالات (Cannibalization)

يفرضها الكود في `scripts/generate-article.mjs` قبل أي توليد:

1. **تخطي المنشور:** الموضوع الذي سبق نشر slug له يُتخطى.
2. **احتواء الكلمة المفتاحية:** إن احتوت كلمة الموضوع الجديد كلمةً منشورة أو العكس (بعد التطبيع العربي) يُتخطى.
3. **تغطية الكلمات ≥ 60%:** إن تغطت كلمات الكلمة المفتاحية القائمة داخل نص الموضوع الجديد (أو العكس) بنسبة 60% فأكثر يُتخطى.
4. **تشابه العناوين > 75%:** عبر Jaccard مع تجذير عربي بسيط.
5. **عند التوليد:** فحص نهائي لتشابه عنوان المسودة مع كل المنشور — الرفض عند التجاوز.

## 4. قواعد جودة وسلامة كل مقال قبل النشر

| الفحص | القاعدة |
|---|---|
| اكتمال المحتوى | مادة تحريرية فعلية غير فارغة؛ لا يوجد حد كلمات إلزامي ولا يُستخدم العدد وحده للحكم على الجودة أو الفهرسة |
| العنوان | 20-75 حرفاً |
| الوصف التعريفي | 100-170 حرفاً (Meta Description) |
| الـ slug | إنجليزي فريد من خطة المحتوى (لا يُولَّد عشوائياً) |
| الجرعات | يُرفض أي رقم جرعة/حبوب/تعليمات دوائية رقمية |
| التواصل | يُرفض أي هاتف/واتساب داخل المتن (الاستشارة تُضاف بقسم رسمي موحد) |
| التجاري | يُرفض أي سعر/بيع/توصيل/صيدلية باسمها |
| الوعود | تُرفض وعود النتائج والنسب المضمونة |
| المصادر | يمنع اختلاق دراسات أو إحصاءات؛ الصياغة العامة موثوقة فقط |
| الروابط الداخلية | يُضمَن رابطان داخليان على الأقل أو تُضاف قسم «اقرئي أيضاً» |
| إخلاء المسؤولية | يُضاف نص إخلاء المسؤولية الدائم + رابط الاستشارة تلقائياً |

## 5. وتيرة النشر

- **3 مقالات يومياً فعلياً**: الجدولة القائمة تعمل 5 مرات يومياً، ويفرض السكربت **سقفاً يومياً بمقدار 3 مقالات** (التشغيلات الإضافية تنتهي برسالة صريحة دون نشر).
- المقال يُنشر فقط إذا اجتاز كل الفحوصات؛ وإلا **يفشل التشغيل ظاهرياً** ولا يُكتب شيء (لا نجاح زائف).
- كل نشر يحدّث تلقائياً: `src/data/articles.json` + `public/sitemap.xml` ثم يرفعهما إلى المستودع.

## 6. دورة تحديث الخطة

- عند استنفاد الطابور يتوقف النشر بفشل واضح حتى تُضاف موضوعات جديدة.
- قواعد إضافة موضوع جديد: نية بحث مغايرة عن كل منشور + كلمة مفتاحية أساسية واحدة + قصد واضح + عنقود محدد + روابط داخلية مخططة.
- المواضيع الحساسة (الأدوية/الإجهاض) تُكتب بزاوية السلامة والتعليم فقط، وتُراجع صياغتها قبل الإضافة.

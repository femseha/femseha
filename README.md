# FemSeha — فيم صحة

منصة عربية للتثقيف الطبي والاستشارات في صحة المرأة والصحة الإنجابية، بإشراف **د. هيثم الخطيب** — اختصاصي جراحة النساء والتوليد والعقم. السوق الأساسي: المملكة العربية السعودية.

> محتوى تعليمي فقط: لا تبيع المنصة الأدوية، ولا تقدم جرعات أو خططاً علاجية فردية. في الحالات الطارئة توجهي فوراً إلى أقرب قسم طوارئ.

## البنية التقنية

- **الإطار:** React 19 + Vite 7 + Tailwind (SPA عربية RTL) — لا تغيّر الإطار.
- **البيانات:** طبقة ملفية ثابتة (لا قاعدة بيانات):
  - `src/data/articles.json` — كل المقالات المنشورة (المصدر الوحيد).
  - `src/data/content-map.json` — خطة المحتوى والكلمات المفتاحية (35 موضوعاً مرتباً بأولوية).
  - `src/data/site.ts` — هوية الموقع وبيانات الطبيب والقنوات الرسمية.
- **النشر:** Vercel (مشروع مرتبط بمستودع GitHub، يبني من `main` عبر `npm run build`).

## أوامر التشغيل

```bash
npm install        # تثبيت التبعيات
npm run dev        # بيئة التطوير
npm run build      # بناء الإنتاج إلى dist/
npm run preview    # معاينة بناء الإنتاج محلياً
```

## خط النشر الآلي (3 مقالات/يوم)

```
.github/workflows/auto-publish.yml   الجدولة والتشغيل (كما هو، دون تعديل)
scripts/generate-article.mjs          التوليد + الفحوصات + الحفظ + الرفع داخل Actions
src/data/content-map.json            طابور الموضوعات المعتمدة
```

- الجدولة الحالية تعمل 5 مرات يومياً؛ **يفرض السكربت سقفاً يومياً بثلاثة مقالات** فعلياً.
- يختار الموضوع التالي من الخطة ويتخطى المنشور والمتنافس كلماتياً.
- يرفض النشر عند فشل أي فحص جودة/سلامة (لا نجاح زائف).
- يكتب في `articles.json` و`sitemap.xml` ثم يرفع عبر GITHUB_TOKEN داخل Actions.
- **يتطلب الوسرّ `GEMINI_API_KEY`** في GitHub Secrets (Settings → Secrets → Actions).
- لكي ينجح الرفع: **Settings → Actions → General → Workflow permissions → Read and write**.
- نسخة محسّنة اختيارية من سير العمل مع شرح التطبيق اليدوي: `docs/auto-publish.workflow.fix.yml`.

اختبار الخط محلياً دون مفتاح API ودون تعديل الملفات:

```bash
node scripts/generate-article.mjs --self-test
```

## متغيرات البيئة

| المتغير | مكان الضبط | الاستخدام |
|---|---|---|
| `GEMINI_API_KEY` | GitHub Secrets (Actions) | توليد المقالات عبر Gemini — **إلزامي للنشر الآلي** |
| `DATABASE_URL` | GitHub Secrets (Actions) | مُصرَّح به في الworkflow توارثاً؛ **غير مستخدم**: التخزين ملفي في هذه المعمارية |
